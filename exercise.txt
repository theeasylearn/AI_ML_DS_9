logistic regression 
----------------------------------------------------------------
There are 2 input features in each exercise.

Exercise 1: FinanceDevelop a logistic regression example that will predict whether a loan applicant will Default ($y=1$) or Not Default ($y=0$) based on two input features: Debt-to-Income ratio ($x_1$) and Credit Score ($x_2$).

Exercise 2: E-CommerceDevelop a logistic regression example that will predict whether an online shopper will Complete a Purchase ($y=1$) or Abandon the Cart ($y=0$) based on two input features: Time spent on site in minutes ($x_1$) and Number of pages viewed ($x_2$).

Exercise 3: Real EstateDevelop a logistic regression example that will predict whether a house will Sell within 30 days ($y=1$) or Take longer ($y=0$) based on two input features: Listing price in hundreds of thousands ($x_1$) and Square footage in thousands ($x_2$).

Exercise 4: ManufacturingDevelop a logistic regression example that will predict whether a factory machine will Fail ($y=1$) or Operate Normally ($y=0$) based on two input features: Operating temperature in °C ($x_1$) and Vibration level ($x_2$).

Exercise 5: Fitness TechDevelop a logistic regression example that will predict whether a fitness app user will Achieve Daily Calorie Goal ($y=1$) or Miss It ($y=0$) based on two input features: Active minutes ($x_1$) and Calories consumed in thousands ($x_2$).
